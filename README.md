# Subsurface data portfolio

A working portfolio documenting my transition toward roles at the
intersection of subsurface geoscience and data science — combining
geological domain knowledge with Python, machine learning, and
geospatial tooling.

## Structure

- `01-force2020-lithology/` — wireline log lithology prediction
  (FORCE 2020 dataset), integrating physics-informed feature
  engineering with ML classification. *(in progress)*
- `02-mineral-prospectivity/` — spatial ML for mineral prospectivity
  mapping using open geoscience datasets. *(planned)*
- `03-plate-reconstruction/` — plate tectonic reconstruction using
  pyGPlates. *(planned)*
- `04-seismic-basics/` — introductory seismic interpretation with
  segyio. *(planned)*
- `notes/` — short technical write-ups accompanying each topic as I
  work through it.

## Background

PhD in Geodynamics (Istanbul Technical University), with a career
spanning structural geology, petroleum systems, mineral exploration,
and geotechnical data QA/QC. This repo tracks my hands-on return to
subsurface data workflows, one topic at a time.
